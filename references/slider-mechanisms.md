# 概念滑块调优与 LECO 机制详解 (Concept Slider Mechanisms)

## 1. 什么是概念滑块 (Concept Sliders / LECO)？
传统的 LoRA 通常是“单一单向特征注入”（如一个角色脸孔、一件特定服装）。而**概念滑块（Concept Sliders）**是基于 **LECO (Low-rank Exposure to Concept Optimization)** 或正负对抗样本训练的“标量方向向量”。

在潜空间（Latent Space）中，滑块 LoRA 定义了一个明确的几何位移轴：
```
  -2.0 ◀───────────── 0.0 ─────────────▶ +2.0
[负向特征极值]      [无偏基线]       [正向特征极值]
  冷艳 / 幼态                      大笑 / 骨相紧致
```

## 2. 本地滑块实测解析

### A. 笑容大小调节神器
* **参数机制**：修改 UNet Cross-Attention 模块中关于表情特征层（`attn2`）的权重走向。
* **效果渐变表**：
  * `0.0`：由底模和正向提示词自由决定默认表情。
  * `+0.5`：嘴角轻扬，微抿浅笑。
  * `+1.0`：标准露齿笑，眼神带笑意（眼角肌肉微收）。
  * `+1.5`：灿烂大笑，极强情绪感染力。
  * `-0.5`：无表情（Poker face），情绪抽离。
  * `-1.0`：高冷清冷，下巴微昂，高级时装秀厌世脸。
  * `-1.5`：严肃甚至微带冷酷气场。

### B. 脸型大小调节神器
* **参数机制**：作用于 UNet 下采样及中层特征（`down_blocks`），微调骨相轮廓。
* **效果渐变表**：
  * `+0.6`：消除轻微下颌赘肉，凸显下颌折角。
  * `+1.2`：标准精致小 V 脸，明星级上镜脸型。
  * `-0.6`：面颊饱满，增加苹果肌软组织厚度。
  * `-1.2`：甜美婴儿肥、圆脸幼态感。

### C. 身材调节器 S-shape body
* **特性**：仅作用于 ResNet 与卷积核通道，完全不干涉面部 Token，因此在大幅调节身体曲线时**绝不出现“换脸”或“脸部畸变”**。
* **权重敏感区**：设计阈值为 `1.5 ~ 2.5`。若设为 `0.6` 基本看不出效果，必须拉到 `1.5` 以上才能明显激活腰臀黄金比。
